# 🧹 Utility Cleanup for macOS

A fast, lightweight, open-source macOS system optimizer inspired by Microsoft PC Manager.

## ✨ Features
- **Smart Boost:** Cleans caches, clears old logs, and refreshes your network in one click.
- **Clear App Caches:** Removes temporary files to free up space.
- **Clean System Logs:** Deletes leftover log files.
- **Flush DNS Cache:** Refreshes your internet connection.
- **Empty Trash:** Quickly reclaims disk space.

## 📥 How to Download & Install (macOS)
1. Click the **Actions** tab at the top of this page.
2. Click the latest build with a **green checkmark (✅)**.
3. Scroll down to **Artifacts** and download **`UtilityCleanup-macOS-Installer`**.
4. Unzip the download, open **`UtilityCleanup-macOS.dmg`**, and drag **Utility Cleanup** into your **Applications** folder!

> **Note for Mac Users:** Since this is a free open-source indie app, macOS may ask for permission the first time you open it. Just **Right-Click** the app -> click **Open** -> click **Open** again!
